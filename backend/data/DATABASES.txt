Relational Databases

A relational database organizes information into tables (relations) composed of rows (tuples) and columns (attributes). This model was proposed by Edgar F. Codd in 1970 and is the most widely used in business applications.

Fundamental Concepts
- Table (Relation): structure that stores data about an entity.
- Row (Tuple): each individual record within a table.
- Column (Attribute): each property or field in a table.
- Primary Key: column or set of columns that uniquely identifies each row.
- Foreign Key: column that references the primary key of another table, establishing relationships between tables.

Normalization
Normalization is the process of organizing tables to reduce redundancy:
- First Normal Form (1NF): each cell contains a single atomic value.
- Second Normal Form (2NF): complies with 1NF and all non-key attributes depend completely on the primary key.
- Third Normal Form (3NF): complies with 2NF and there are no transitive dependencies between non-key attributes.
- Boyce-Codd Normal Form (BCNF): stricter version of 3NF.

SQL (Structured Query Language)
SQL is the standard language for interacting with relational databases:
- SELECT: query data. Example: SELECT name, age FROM students WHERE age > 20SERT: add records. Example: INSERT INTO students (name, age) VALUES (‘Ana’, 22);
- UPDATE: modify existing records. Example: UPDATE students SET age = 23 WHERE name = ‘Ana’;
- DELETE: delete records. Example: DELETE FROM students WHERE name = ‘Ana’;
- JOIN: combine data from multiple tables. Types: INNER JOIN, LEFT JOIN, RIGHT JOIN, FULL JOIN.

Transactions and ACID properties
A transaction is a set of operations that are executed as a unit:
- Atomicity: all operations are completed or none are.
- Consistency: the database moves from one valid state to another valid state.
- Isolation: concurrent transactions do not interfere with each other.
- Durability: confirmed changes persist even in the event of system failures.

Indexes
Indexes are structures that speed up queries:
- B-Tree index: balanced tree structure, ideal for range and equality searches.
- Hash index: efficient for exact equality searches.
- Composite index: combines multiple columns to optimize frequent queries.


Popular management systems
- PostgreSQL: open source, robust, with support for advanced types and extensions.
- MySQL: widely used in web applications, acquired by Oracle.
- SQLite: lightweight, serverless, ideal for embedded applications.
- Oracle Database: enterprise solution with high performance and scalability.
- SQL Server: from Microsoft, integrated with the .NET ecosystem.
