Sistemas Operativos

Un sistema operativo (SO) es el software fundamental que gestiona el hardware del ordenador y proporciona servicios a los programas de aplicación. Actúa como intermediario entre el usuario y el hardware.

Funciones principales
- Gestión de procesos: creación, planificación y terminación de procesos.
- Gestión de memoria: asignación y liberación de memoria principal (RAM).
- Gestión de archivos: organización, almacenamiento y acceso a ficheros en disco.
- Gestión de dispositivos: control de periféricos mediante drivers.
- Seguridad y protección: control de acceso a recursos del sistema.

Procesos e hilos
Un proceso es un programa en ejecución con su propio espacio de direcciones. Un hilo (thread) es la unidad mínima de ejecución dentro de un proceso.
- Proceso: tiene su propio espacio de memoria, contexto de ejecución y recursos.
- Hilo: comparte el espacio de memoria del proceso padre. Es más ligero de crear y destruir.
- Multithreading: permite ejecutar múltiples hilos concurrentemente dentro de un proceso.

Planificación de procesos
El planificador (scheduler) decide qué proceso ejecutar:
- FCFS (First Come, First Served): ejecuta procesos en orden de llegada. Simple pero puede causar convoy effect.
- SJF (Shortest Job First): prioriza el proceso más corto. Óptimo en tiempo de espera medio pero difícil de implementar.
- Round Robin: asigna un quantum de tiempo a cada proceso en turnos. Justo pero puede tener mucho cambio de contexto.
- Prioridades: cada proceso tiene una prioridad. Riesgo de inanición (starvation) para procesos de baja prioridad.

Gestión de memoria
- Paginación: divide la memoria en páginas de tamaño fijo. Elimina la fragmentación externa.
- Segmentación: divide la memoria en segmentos de tamaño variable según la estructura lógica del programa.
- Memoria virtual: permite usar más memoria de la disponible físicamente mediante el uso de disco (swap).
- Tabla de páginas: estructura que mapea direcciones virtuales a direcciones físicas.

Sistemas de archivos
Un sistema de archivos organiza los datos en disco:
- FAT32: simple, compatible con casi todos los SO, pero limitado a archivos de 4 GB.
- NTFS: sistema de archivos de Windows, con soporte para permisos, cifrado y archivos grandes.
- ext4: estándar en Linux, con journaling y soporte para volúmenes grandes.
- APFS: sistema de archivos moderno de Apple, optimizado para almacenamiento flash.

Concurrencia y sincronización
Cuando múltiples procesos acceden a recursos compartidos pueden surgir problemas:
- Condición de carrera (race condition): resultado depende del orden de ejecución.
- Exclusión mutua (mutex): mecanismo que garantiza que solo un proceso accede al recurso a la vez.
- Semáforos: variable entera que controla el acceso a recursos compartidos.
- Deadlock: situación donde dos o más procesos se bloquean mutuamente esperando recursos del otro.

Tipos de sistemas operativos
- Monolítico: todo el sistema operativo funciona en un solo espacio (Linux).
- Microkernel: solo funciones esenciales en el kernel, el resto en espacio de usuario (Minix).
- Híbrido: combina aspectos de ambos enfoques (Windows NT, macOS).
- Tiempo real (RTOS): garantiza tiempos de respuesta deterministas para aplicaciones críticas.
