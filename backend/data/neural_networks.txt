Artificial Neural Networks

Artificial neural networks (ANNs) are computational models inspired by the structure of the human brain. They are made up of interconnected nodes called artificial neurons, organized in layers.

Basic structure
A typical neural network has three types of layers:
- Input layer: receives the problem data.
- Hidden layers: process the information using activation functions.
- Output layer: produces the final result.

Each connection between neurons has an associated weight that is adjusted during training. The training process seeks to minimize a loss function by comparing the predicted output with the expected output.

Activation functions
Activation functions introduce non-linearity into the model:
- Sigmoid: maps values to the range (0, 1). Historically used in hidden layers.
- ReLU (Rectified Linear Unit): returns max(0, x). Currently the most popular due to its computational efficiency.
- Tanh: maps values to the range (-1, 1). Similar to sigmoid but centered at zero.
- Softmax: used in the output layer for multi-class classification problems.

Types of neural networks
- Multilayer perceptron (MLP): the simplest form, with fully connected layers.
- Convolutional neural networks (CNN): specialized in image processing. They use filters that detect local patterns.
- Recurrent neural networks (RNN): designed for sequential data such as text or time series. They have connections that form cycles.
- Transformers: modern architecture based on attention mechanisms. Basis for models such as GPT and BERT.

Training
Neural network training is performed by:
1. Forward pass: the data passes through the network and the prediction is calculated.
2. Error calculation: the prediction is compared with the actual value using the loss function.
3. Backpropagation: the error gradients are calculated for each weight.
4. Weight update: the weights are adjusted using an optimizer (SGD, Adam, etc.).

This process is repeated over multiple epochs until the model converges.

Common problems
- Overfitting: the model memorizes the training data and does not generalize well. This is mitigated with regularization, dropout, or more data.
- Underfitting: the model is too simple to capture patterns. This is solved by increasing the complexity of the model.
- Vanishing gradients: gradients become very small in deep networks, making it difficult to train the first layers.

Applications
Neural networks are used in image recognition, natural language processing, autonomous driving, diagnosis, etc.
